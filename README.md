# partnersim-dynet-sti

Agent-based SIS transmission model that runs on top of the dynamic partnership networks generated by [`partnersim-dynet`](https://github.com/pnt-id-models/partnersim-dynet).

| Package | Purpose |
|---|---|
| [`partnersim-dynet`](https://github.com/pnt-id-models/partnersim-dynet) | Core partnership network simulator |
| [`partnersim-dynet-lhs`](https://github.com/pnt-id-models/partnersim-dynet-lhs) | Latin Hypercube Sampling calibration sweeps |
| `partnersim-dynet-sti` | STI transmission modelling (this package) |


## Installation

Requires Python 3.11 (Python 3.12 is not currently supported).

```bash
poetry env use /usr/bin/python3.11
poetry install
```
## Quick start

The workflow is to run single or multiple disease models by varying random seed on an already generated partnersim-dynet partnership network model replicate 

```python
from partnersim_dynet_sti import net_result_from_dir, run_sti_on_result, SISConfig
from partnersim_dynet_sti.outputs import collate_demographic_summaries, infection_rate_table
 
# Point at an existing partnersim-dynet replicate output directory.
# The network must have been generated with the parameters and its partnership data must be available in this directory.
REPLICATE_DIR = "partnersim-dynet/examples/output/sweep/full_sweep_15pcconcurrency_15000agents_18Aug2026_#11/replicate_380863079"
SEED = 380863079
N_DISEASE_REPLICATES = 100
INFECTION_START_STEP = 51  # must match SISConfig below
 
net = net_result_from_dir(output_dir=REPLICATE_DIR, seed=SEED)
 
# Returns a list of STIRunResult objects, one per disease replicate, each with
# its own output directory, network seed, and disease seed.
sti_results = run_sti_on_result(
    net_result=net,
    sis_cfg=SISConfig(
        infection_prob=0.20,
        recovery_prob=0.10,
        infection_start_step=INFECTION_START_STEP,
        initial_infected=0.10,
    ),
    seeds=list(range(N_DISEASE_REPLICATES)),
    output_dir=REPLICATE_DIR,
    verbose=True,
)
 
# Demographic summaries feed the infection-rate / reinfection-rate table
# (one row per agent, including agents who were never infected).
collated = collate_demographic_summaries(sti_results)
table = infection_rate_table(collated)
table.to_csv(f"{REPLICATE_DIR}/infection_rate_table.csv", index=False)
```
 
Or run the full worked example:
 
```bash
poetry run python examples/run_disease_on_selected.py
```

## Disease model

Homogeneous SIS model:
- All agents have identical `infection_prob` (β) and `recovery_prob` (γ)
- At each timestep the contact graph is built from active partnerships using `partnersim_dynet.network.build_graph_at`
- Each I agent independently infects each S neighbour with probability β
- Each I agent independently recovers to S with probability γ (infectious period, mean = 1/γ steps)


### Outputs 

| File | Contents |
|---|---|
| `disease_summary.csv` | Per-timestep S, I, R₀, R_eff, reinfection counts |
| `infection_events.csv` | Every transmission event with infector/receiver IDs |
| `infection_rate_table.csv` | Built separately via `collate_demographic_summaries` + `infection_rate_table` containing one row per agent (including never-infected agents), for infection/reinfection-rate analysis across multiple disease replicates |
